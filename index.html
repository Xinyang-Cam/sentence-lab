03 / HOW DOES THIS WORK?How does a computer compare meanings?+
“Hello” →

1. Turn words into numbers

A model turns each sentence into a list of 384 numbers, called a sentence embedding.

↗ ↗ ∠

2. Compare patterns

Think of each sentence as an arrow in a giant mathematical space. Cosine similarity compares their directions.

−1 ← 0 → +1

3. Read the score carefully

+1: same direction. 0: right angle. −1: opposite direction. These are vector relationships, not guaranteed relationships between meanings.

The machine measures patterns, not perfect understanding. A score is neither a percentage nor a probability. Even similar sentences can differ in crucial ways; this browser runs quantized model weights.
